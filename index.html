Apa Itu Coding?

Coding (pemrograman) adalah cara kita berkomunikasi dengan komputer dengan menuliskan serangkaian instruksi atau perintah menggunakan bahasa khusus. Tanpa coding, perangkat seperti HP, laptop, sistem kecerdasan buatan (AI), hingga game favoritmu tidak akan bisa berjalan!

Dengan menguasai coding, kamu bisa membangun karya digital sendiri—mulai dari membuat kerangka tampilan web, mendesain antarmuka yang modern, hingga mengatur logika program agar aplikasi berjalan otomatis.

HTML (HyperText Markup Language)

HTML adalah fondasi dan pondasi utama dari setiap situs web di dunia. Ibarat sebuah bangunan rumah, HTML berperan sebagai tiang, tembok, dan pondasi dasar yang membentuk struktur bangunan tersebut.

File utama dari sebuah website biasanya diberi nama index.html. Nama ini merupakan standar global yang dibaca pertama kali oleh browser saat kamu mengunjungi suatu domain web.

Fungsi Elemen Utama HTML:

• <h1> hingga <h6>: Judul utama & sub-judul artikel.
• <p>: Paragraf teks biasa.
• <img>: Menyisipkan gambar dari penyimpanan atau internet.
• <a>: Link pembuka halaman lain.

<!DOCTYPE html> <html lang="id"> <head> <title>Halaman Utama Saya</title> </head> <body> <h1>Selamat Datang di Web Saya!</h1> <p>Ini adalah paragraf pertama saya.</p> </body> </html>

CSS (Cascading Style Sheets)

Jika HTML adalah pondasi rumah, maka CSS adalah cat dinding, dekorasi interior, gorden, dan tata pencahayaannya. Tanpa CSS, tampilan website hanya akan tampak polosan berupa teks hitam putih di atas kertas polos.

CSS memungkinkan kamu mengatur jenis font yang estetis, memberikan warna latar belakang (*background*), memberikan efek animasi transisi halus, hingga mengatur agar tampilan web responsif di layar HP maupun laptop.

body { background-color: #f8fafc; color: #0f172a; } .tombol-keren { background-color: #2563eb; color: white; }

JavaScript (JS)

JavaScript adalah otak atau sistem penggerak yang membuat website menjadi hidup dan interaktif. Jika HTML membentuk tubuh dan CSS memberikan pakaian cantik, maka JavaScript yang memberikan kemampuan bergerak dan berpikir!

function sapaPengguna(nama) { tampilkanModal("Selamat Datang", "Halo " + nama + ", selamat datang!"); }

Python (Pemrograman Server & AI)

Python adalah salah satu bahasa pemrograman paling populer dan paling disukai oleh pemula di seluruh dunia. Alasan utamanya adalah tata bahasa (*sintaks*) Python sangat ringkas dan mudah dibaca seperti bahasa Inggris sehari-hari.
